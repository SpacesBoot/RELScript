# RELScript
Rules for the REL language.

# Rules

1. REL requires the use of mandatory {} for better code writing and reading.
2. Any rel interpreter created must be open source.
3. REL requires the use of parentheses () for arguments, and only for that; anything outside of arguments will not require parentheses, but neither will they be rejected.
4. REL limits the amounts per line to 1 (Example using math; -> good, using math, utils; -> bad).

# Final

The use of these rules is mandatory for that interpreter to be considered rel.
